# 世界观生成规则

## 任务说明

根据已生成的基础设定和人物体系，构建一个完整、自洽、有沉浸感的世界观体系。世界观应为故事提供坚实的舞台背景，并为情节发展和角色成长提供合理的逻辑支撑。

## 生成要求

### 世界类型（world_type）
- 用简明的标签分类世界观类型
- 常见类型：东方仙侠世界、西方奇幻大陆、现代都市、末日废土、星际科幻、架空历史、平行宇宙、异世界穿越等
- 类型标签应与基础设定中的故事背景保持一致

### 地理环境（geography）
- 描述故事发生的**主要地域**及其特征
- 包含关键地点的名称、地理特征和叙事意义（例如：主角的故乡、重要战场、核心势力所在地）
- 地域之间的**空间关系**和**距离概念**要合理，为后续角色的行动路线提供依据
- 环境描写应有独特性，避免泛泛的"一座大山""一片森林"式描述
- 字数不少于 200 字

### 社会结构（society）
- 阐述这个世界的**社会组织形式**：帝制/门派制/公司制/部落制/联邦制等
- 描述**阶层分化**和**权力结构**：谁掌握权力？权力的来源是什么？底层与上层的关系如何？
- 说明社会中的**主要矛盾**（阶级矛盾、种族矛盾、新旧势力冲突等），这些矛盾应与故事的核心冲突形成呼应
- 描述普通人在这个社会中的**日常生活状态**，增强真实感
- 字数不少于 200 字

### 力量/能力体系（power_system）
- 如果故事类型涉及超自然力量（仙侠、玄幻、奇幻、超能力等），必须详细定义力量体系
- 包含以下要素：
  - **力量来源**：灵气、魔力、血脉、科技、精神力等
  - **等级划分**：明确的等级体系和晋升条件（如修仙的筑基→金丹→元婴）
  - **能力分类**：不同流派或属性的区分
  - **限制与代价**：使用力量的代价和限制条件，避免角色无限开挂
  - **稀有度分布**：各等级的人数比例，体现金字塔结构
- 如果是现代都市等非超自然类型，此字段描述**社会资源和影响力**的获取方式
- 字数不少于 200 字

### 重要历史事件（history）
- 梳理 **3-5 个**塑造当今世界格局的关键历史事件
- 每个事件应包含：发生时间（相对时间即可）、核心内容、对当今世界的影响
- 历史事件之间应有**因果逻辑链条**，而非孤立的点
- 至少有一个历史事件与故事的核心冲突或主角的命运存在**隐秘的关联**（可作为后续伏笔）
- 字数不少于 250 字

### 文化特色（culture）
- 描述这个世界独特的**文化习俗、信仰体系、禁忌规范**
- 包含人们的**价值取向**：崇尚什么？鄙视什么？
- 提及特有的**节日、仪式、礼节**等文化符号
- 文化设定应为角色行为和社会冲突提供合理的文化背景支撑
- 字数不少于 150 字

### 科技/文明水平（technology）
- 明确这个世界的**科技或文明发展程度**
- 如果是架空世界，说明与现实世界的科技差异（例如：有炼丹术但没有火药、有飞剑但没有马车）
- 科技水平的设定应与力量体系和社会结构逻辑自洽
- 描述日常生活中常见的**交通、通讯、生产方式**
- 字数不少于 100 字

### 世界规则（rules）
- 列举 **3-6 条**这个世界运行的**底层规则和硬性约束**
- 规则应是明确的、不可轻易打破的（如果打破则会有严重后果）
- 示例：
  - "修炼者每次突破大境界必须渡劫，渡劫失败则形神俱灭"
  - "不同种族之间的结合会导致后代失去魔力"
  - "死者复活的禁术需要以等价的生命为代价"
- 规则的设计应为故事制造**张力和限制**，避免主角轻易解决所有问题

## 生成策略

1. 以基础设定的故事背景和核心冲突为出发点，构建与之匹配的世界框架
2. 世界观的各要素之间必须**逻辑自洽**——地理影响社会结构，社会结构影响文化，力量体系影响阶层分化
3. 融入为角色和情节服务的细节——世界观不是孤立的百科全书，每个设定都应该在后续故事中能被用到
4. 在类型惯例的基础上加入**独特的创新元素**，让这个世界有辨识度
5. 保持适度的**留白**——不需要穷尽每一个细节，为后续创作留出自由发挥的空间

## 输出格式

严格按以下 JSON 结构返回：

```json
{
  "world_type": "世界类型标签",
  "geography": "地理环境的详细描述文本",
  "society": "社会结构的详细描述文本",
  "power_system": "力量/能力体系的详细描述文本",
  "history": "重要历史事件的详细描述文本",
  "culture": "文化特色的详细描述文本",
  "technology": "科技/文明水平的描述文本",
  "rules": [
    {"rule": "规则一的内容", "source": "规则的来源或成因"},
    {"rule": "规则二的内容", "source": "规则的来源或成因"},
    {"rule": "规则三的内容", "source": "规则的来源或成因"}
  ]
}
```

## 注意事项

- 所有文本字段使用中文
- rules 字段为 JSON 数组，每条规则包含 rule（规则内容）和 source（来源或成因）两个字段
- geography、society、power_system、history 等长文本字段内容要充实详实，不可敷衍
- JSON 字符串中的换行使用 `\n` 转义
- 不要在 JSON 之外输出额外内容
- 确保世界观设定与前序步骤生成的基础设定和人物体系**不矛盾**
