# 人物生成规则

## 任务说明

根据已生成的基础设定（故事背景、核心冲突、基调等），生成一套完整的人物体系，包括主角、反派和配角，以及角色之间的关系网络。

## 生成要求

### 主角（protagonist）
- **姓名（name）**：符合故事时代和文化背景的名字，避免过于奇特或拗口。古代背景可用雅致的古风名，现代背景用常见但有记忆点的名字
- **性格（personality）**：不少于 **150 字**。要求多维度、有层次感。不要只写优点，必须包含性格缺陷或矛盾面。例如：外表冷漠内心柔软、看似大大咧咧实则心思缜密。描述时应具体到行为表现层面，而非抽象词汇堆砌
- **背景（background）**：不少于 **200 字**。交代出身、成长经历、重要转折事件。背景应能合理解释角色的性格成因和核心动机。避免"天赋异禀+家族遭难"的套路化设定，力求独特且有情感共鸣
- **外貌（appearance）**：写出辨识度高的外在特征。不要泛泛写"英俊/美丽"，而要有标志性细节（如一道疤、特殊瞳色、习惯性动作等）。外貌描写应服务于人物塑造
- **核心动机（motivation）**：角色行动的根本驱动力。动机应深层且有情感重量，不仅仅是"变强/复仇/拯救世界"这类表面目标，还要挖掘背后的情感需求
- **成长弧线（arc）**：角色从故事开始到结束的内在变化轨迹。应包含起点状态、关键转变节点和最终状态。弧线设计要与核心冲突紧密关联

### 反派（antagonist）
- 与主角同等深度的完整设定，不可扁平化
- 反派必须有**合理的行为逻辑**和**自洽的价值观**，不能是纯粹为恶而恶
- 反派的动机最好能与主角形成**镜像对照**——他们可能有相似的出发点，但走向了不同的道路
- 反派应有令人信服的**实力基础**和**资源背景**，能构成真正的威胁

### 配角（supporting，2-4 个）
- 每个配角应有**明确的叙事功能**：导师、挚友、情感线对象、信息提供者、对照组等
- 性格和背景虽可简于主角，但仍需立体可信，不做纯工具人
- 每个配角应有自己的**小目标或诉求**，不只是围绕主角转
- 配角之间的组合应制造丰富的**化学反应**和戏剧冲突

### 关系网络（relationships）
- 每个角色的 relationships 字段中，明确标注与**其他角色的关系**
- 关系描述应包含三个维度：
  - **target**：关系对象的姓名
  - **relation**：关系类型（如师徒、宿敌、暗恋、竞争对手、亦敌亦友等）
  - **dynamic**：关系动态——这段关系会如何发展变化（如"初期对立，中期因共同目标暂时合作，后期因理念分歧再次决裂"）
- 关系网络中应包含至少一组**张力关系**（存在根本矛盾但又无法彻底切割的关系）

## 生成策略

1. 先通读已有的基础设定，理解故事的核心冲突和主题方向
2. 从核心冲突出发，设计与冲突双方直接关联的主角和反派
3. 根据剧情需要和角色成长弧线的需求，规划配角阵容
4. 检查所有角色是否覆盖了推动故事发展所需的所有关键角色功能
5. 编织关系网络时，确保角色之间存在足够的戏剧张力和互动空间
6. 最终检视：每个角色是否有独特的辨识度？是否会被读者记住？

## 输出格式

以 JSON 数组返回所有角色，严格遵循以下结构：

```json
[
  {
    "name": "角色姓名",
    "role": "protagonist",
    "personality": "不少于150字的性格描述...",
    "background": "不少于200字的背景故事...",
    "appearance": "外貌特征描写",
    "motivation": "核心动机",
    "arc": "成长弧线描述",
    "relationships": [
      {
        "target": "另一角色姓名",
        "relation": "关系类型",
        "dynamic": "关系发展动态"
      }
    ]
  },
  {
    "name": "反派姓名",
    "role": "antagonist",
    "personality": "...",
    "background": "...",
    "appearance": "...",
    "motivation": "...",
    "arc": "...",
    "relationships": [...]
  },
  {
    "name": "配角一姓名",
    "role": "supporting",
    "personality": "...",
    "background": "...",
    "appearance": "...",
    "motivation": "...",
    "arc": "...",
    "relationships": [...]
  }
]
```

## 注意事项

- role 字段仅限三个值：`protagonist`、`antagonist`、`supporting`
- 主角和反派各 **1 个**，配角 **2-4 个**
- 所有文本字段使用中文
- relationships 中的 target 必须是本次生成的其他角色的 name，不可引用不存在的角色
- JSON 字符串中的换行使用 `\n` 转义
- 不要在 JSON 之外输出额外内容
