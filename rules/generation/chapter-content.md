# 正文撰写规则

## 正文撰写核心要求

- **字数控制**：严格按照目标字数生成，允许 ±10% 浮动。例如目标 3000 字，实际产出应在 2700-3300 字之间。
- **开头要求**：必须承接上一章结尾，自然过渡进入本章内容。不要复述或重复上一章已经写过的情节，而是以新的动作、对话或场景切入。
- **结尾要求**：章末必须设置钩子——可以是悬念（未解之谜）、反转（出人意料的转折）、或新问题（引发读者好奇），制造强烈的翻页欲望。
- **叙事视角**：全文保持 POV（叙事视角）一致性。若为第三人称限制视角，不可突然切换到其他角色的内心活动；若为全知视角，也应以主要视角人物为重心。
- **对话占比**：对话内容应占全章 30%-40%。对话要口语化、有个性特征、能推动情节发展或揭示人物关系。避免说教式对话和信息倾倒式对话。
- **描写层次**：综合运用多维感官描写——视觉（色彩、光影、动作）、听觉（声响、语调）、嗅觉（气味）、触觉（温度、质感）、情感（角色内心波动），让场景立体鲜活。
- **节奏控制**：紧张与舒缓交替推进，避免全篇节奏单一。动作戏后安排喘息空间，安静段落后制造突发事件。
- **Show don't tell**：通过动作、对话、细节展现人物性格和情绪，避免直白描述。例如不写"她很紧张"，而写"她的指甲陷进掌心，在皮肤上留下几道月牙形的白印"。

## 上下文衔接规则

- **承接上文**：必须参考上一章结尾原文（至少最后 1500 字），确保场景、人物状态、对话语境的自然过渡。
- **状态一致**：必须参考叙事状态快照中记录的角色状态（位置、情绪、伤势等）、已知信息、持有物品，不可出现矛盾。
- **伏笔回收**：对照伏笔追踪列表，在适当时机回收已埋下的伏笔，回收方式要自然合理，不可生硬。
- **时间线连续**：保持故事时间线的连续性，不可出现时间矛盾（如白天突然变成夜晚却无过渡、前一章刚过了三天本章又说昨天发生的事）。
- **空间逻辑**：角色的位置移动要合理，不可出现"瞬移"现象（前一段还在A地，下一段无交代就到了B地）。

## 去 AI 味基础要求

- **避免高频词**：禁用以下 AI 典型高频词汇——"不禁"、"竟然"、"仿佛"、"宛如"、"犹如"、"不由得"、"缓缓"、"淡淡"、"微微"。如需表达相近含义，换用更具体、更有画面感的表达。
- **避免排比滥用**：不要连续使用三个以上的排比句式，尤其避免"他……他……他……"或"是……是……是……"的机械排列。
- **对话口语化**：对话不要书面化、文绉绉。真实的人说话会省略、会打断、会用口头禅、会答非所问。根据角色身份调整用语习惯。
- **句式多变**：避免每段开头都用"他/她"起笔。交替使用动作起笔、环境起笔、对话起笔、感官起笔等多种方式。
- **替代直白叙述**：用动作细节和环境描写替代心理直白叙述。不写"气氛很尴尬"，而写"沉默像一块湿毛巾，把两个人之间的空气都捂得透不过气来"。
- **避免总结式段落**：不要在段落末尾用一句话总结前面写了什么。让情节和画面自己说话。
- **避免过度修辞**：不要每句话都加比喻或形容词。朴素的短句有时比华丽的长句更有力量。

## 输出格式

直接输出小说正文纯文本，不要 JSON 包装，不要 Markdown 格式标记，不要添加章节标题（标题由系统自动处理），不要在正文前后添加任何元信息或注释。
