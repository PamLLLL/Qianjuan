# 基础设定生成规则

## 任务说明

根据用户提供的小说类型（genre）、核心创意（concept）、目标字数（target_words）和目标平台（target_platform），生成一套完整的小说基础设定方案。

## 生成要求

### 标题建议（title_suggestions）
- 生成 **3-5 个**候选标题
- 每个标题附带简短的选择理由（rationale），说明该标题的寓意或吸引力
- 标题风格应符合目标平台的偏好（如起点偏大气磅礴，番茄偏通俗直白）
- 标题长度控制在 2-8 个字，朗朗上口，易于记忆
- 避免与知名作品重名或高度相似
- 至少包含一个悬念型标题和一个直白型标题，给用户多样化选择

### 故事背景（background）
- 明确故事发生的**时代**（古代/现代/未来/架空）
- 明确**世界类型**（现实世界/修仙世界/西幻世界/末日世界/平行宇宙等）
- 描述核心的**社会环境**和**时代特征**
- 字数不少于 150 字，内容具体而非笼统

### 整体基调（tone）
- 用简洁精准的词汇概括故事的整体氛围
- 示例：热血燃向、轻松搞笑、暗黑压抑、温馨治愈、悬疑烧脑、史诗恢弘
- 基调应与小说类型和目标读者群匹配

### 核心冲突（core_conflict）
- 明确故事的**根本矛盾**是什么
- 说明冲突的**双方或多方**势力/立场
- 解释这一冲突**为什么不可调和**，驱动整个故事发展
- 字数不少于 100 字

### 主题（themes）
- 提炼 2-4 个贯穿全书的深层主题
- 例如：成长与蜕变、权力与腐败、爱与牺牲、命运与抗争、人性的光暗
- 主题应与核心冲突呼应，且不过于空泛

### 目标读者画像（target_audience）
- 描述理想读者的**年龄段、性别倾向、阅读偏好**
- 分析这类读者的**核心诉求**（如代入感、爽感、情感共鸣、智力挑战）
- 说明这部小说如何满足这些诉求
- 字数不少于 80 字

### 差异化卖点（unique_selling_point）
- 明确这部小说与同类型作品的**最大不同**是什么
- 为什么读者应该选择看这本而非同题材的其他作品
- 卖点应具体可感，不要泛泛而谈
- 字数不少于 80 字

## 生成策略

1. 首先分析用户的核心创意，提取关键元素和潜在方向
2. 结合小说类型的市场特征和目标平台的读者偏好进行设定
3. 确保所有设定要素之间的**逻辑一致性**（如基调与冲突匹配、读者画像与卖点呼应）
4. 在类型惯例的基础上融入创新元素，避免千篇一律

## 输出格式

严格按以下 JSON 结构返回：

```json
{
  "title_suggestions": [
    {"title": "标题一", "rationale": "选择理由"},
    {"title": "标题二", "rationale": "选择理由"},
    {"title": "标题三", "rationale": "选择理由"}
  ],
  "background": "故事背景设定的详细描述文本",
  "tone": "整体基调关键词",
  "core_conflict": "核心冲突的详细描述文本",
  "themes": ["主题一", "主题二", "主题三"],
  "target_audience": "目标读者画像的描述文本",
  "unique_selling_point": "差异化卖点的描述文本"
}
```

## 注意事项

- 所有文本字段使用中文
- JSON 字符串中的换行使用 `\n` 转义
- 不要在 JSON 之外输出额外内容
- 确保 JSON 格式合法，可被程序直接解析
